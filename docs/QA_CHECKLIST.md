# QA checklist before moving from 20 to 150

## Provenance
- [ ] A source document body was collected, not a headline/summary snippet.
- [ ] Original publication date independently checked against dated primary record.
- [ ] Text actually represents content publicly available at the attributed time.
- [ ] Every material assertion has a direct quote and passing SHA-256 verification.
- [ ] Proposed/enacted/effective statuses correctly separated.

## Frame and selection
- [ ] Every retrieved record kept, even when screened out.
- [ ] API pagination/time window complete or exact coverage gap documented.
- [ ] Excluded-document random audit performed; missed-event rate estimated.
- [ ] Economic materiality adjudicated without outcome knowledge.
- [ ] Underlying event dedup, revision chains, split/multi-event documents assessed.
- [ ] Source/year representation matches predeclared sampling plan.
- [ ] Same seed + same frame => identical selected IDs and hashes.

## Independent verification
- [ ] Codex review produced actual reproducible findings and tests.
- [ ] Human reviewer used original sources and attested dates.
- [ ] Pilot research limitations documented before scale-up.
- [ ] No revenue, popularity, market outcomes used for selection or extraction.
- [ ] No undocumented protocol changes; deviations recorded.
