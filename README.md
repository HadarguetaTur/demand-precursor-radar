# Demand Precursor Radar — Historical Events Research Kit

ערכת התחלה ל־**מדגם היסטורי אמיתי, מבוקר וניתן לשחזור** של אירועי שינוי, לצורך בדיקה מאוחרת של יכולת חיזוי ביקוש. כוללת סוכני Claude Code, הוראות Codex, פרוטוקול מחקר, קוד Python עובד, בדיקות יחידה ומדריך הפעלה.

**מה יש עכשיו:** מסגרת עבודה לפיילוט של 20 אירועים, מחבר ממשלתי רשמי אחד (Federal Register), סינון, חילוץ בסיסי, חילוץ LLM אופציונלי, אימות מקור וציטוטים, אישור אנושי, דגימה אקראית שכבתית, מניפסט והקפאה.

**מה אין עכשיו:** 20 או 150 אירועים שנאספו בפועל, חיבורי מקור מעבר לראשון, אימות היסטורי ידני, ביקורת Codex שבוצעה בפועל, או הוכחה שביקוש ניתן לחיזוי. **קוד ואוטומציה אינם מחקר שהושלם.**

## התחלה תוך דקה

1. חלצי את ה־ZIP ושמרי את התיקייה במחשב.
2. קראי את [`docs/START_HERE.md`](docs/START_HERE.md).
3. פתחי טרמינל בשורש התיקייה והריצי:

```bash
python -m pip install -e .
python -m unittest discover -s tests -v
python -m radar --help
```

4. פתחי את אותה תיקייה ב־Claude Code ואמרי לו לעבוד לפי `PROMPTS.md` ו־`PLANS.md`.
5. השתמשי ב־Codex לביקורת עצמאית דרך `.codex/prompts/independent-audit.md`.

## קבצים עיקריים

| מיקום | תפקיד |
|---|---|
| `AGENTS.md` | עקרונות מחקר, משותפים לקלוד ולקודקס |
| `CLAUDE.md` | הוראות Claude Code והפניה לסוכנים |
| `.claude/agents/` | ארבעה סוכני משנה לקריאת מקורות וביקורת |
| `.claude/skills/research-event-audit/` | צ'קליסט אימות אירוע |
| `.codex/prompts/` | תסריטי ביקורת עצמאית עבור Codex (לא מופעלים אוטומטית) |
| `protocol/` | פרוטוקול, כללי הכללה, מקורות ודגימה |
| `src/radar/` | קוד Python עם CLI שניתן להפעיל |
| `tests/` | בדיקות מבוססות דוגמאות **סינתטיות בלבד** |
| `data/` | מקורות אמיתיים שנאספים בהרצה, לא כלולים מראש |
| `docs/QA_CHECKLIST.md` | תנאים לפני הרחבה ל־150 |

## עיקרון מרכזי

המאגר חייב לכלול *אירועים שניתן היה לזהות בזמן אמת*, ולא הצלחות שאנחנו יודעים היום לספר עליהן בדיעבד. התוצאות המאוחרות נשארות מחוץ לפרויקט עד שהמדגם מוקפא.

## אישור מגבלות

מחקר רחב דורש יותר ממקור אחד, ביקורת של מסמכים שהסינון פסל, אימות תאריך הפרסום המקורי, ותכנון איכות לפי הטיות ייצוג. לכן קוד ההקפאה הסופית של N=150 **חסום בכוונה** עד להשלמת השערים האלה. זו הגנה על התוקף המדעי, לא באג.
